    for getting user input and change board
    
        derived player method to display rules per player type called from the main game object

        derived player classes will store rules and do validation and will return a board_data_change type
        
        derived player classes will not store any data that is sent to board, simply constructs and returns a pakage
        
        derived players can be const, if we only instantiate them through user_input, as there we instantiate with symbol
        
        derived players class will be read only and or return a pakage which is a const class to store data
        
        derived players can be instnatiated with it not being const, but its features are limited
    
    
        board data will take in data from board_data_change type then read it and make modificatoins to its own class accordingly
        
        
    for making chnages to the board
    
        first create a board pakage object
        
        this object will contain data of what spot to change and what to
        
        the board class will pass in the pakage as a const object than, read and make changes to its data from it
        
        then it will delete the pakage
        
    for making changes to the board
    
        call methods from board class by player validation method, validate throgh player interface then pass in data to board methods
        
        create specific methods in board, to modify board data, each method has a single way to make changes
        
        example, swap marks, pass in 2 spots than board method will modify the board data
